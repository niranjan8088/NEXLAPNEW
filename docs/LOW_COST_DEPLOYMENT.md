# Low-Cost Enterprise Production VPS Deployment Guide

This guide details step-by-step instructions for deploying NexLapTech on a single low-cost Linux VPS ($6 - $12 / month) with Cloudflare Free, Nginx, PM2, and Supabase.

---

## 1. Cost Breakdown & Stack Overview

| Component | Service Provider | Monthly Cost |
| :--- | :--- | :--- |
| **Compute VPS** | Hetzner CPX11 / DigitalOcean 2GB RAM | $6.00 / month |

## 2. Server Provisioning & Firewall Setup

```bash
# 1. Update OS packages
sudo apt update && sudo apt upgrade -y

# 2. Install Node.js 20 LTS, Nginx, and Certbot
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx certbot python3-certbot-nginx git

# 3. Install PM2 process manager
sudo npm install -g pm2

# 4. Enable UFW Firewall
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw --force enable
```

---

## 3. Cloudflare DNS & SSL Configuration

1. In **Cloudflare DNS**:
   - Add `A` record for `www` -> `YOUR_VPS_PUBLIC_IP` (Proxy: Proxied / Orange Cloud).
   - Add `A` record for `@` -> `YOUR_VPS_PUBLIC_IP` (Proxy: Proxied / Orange Cloud).
   - Add `A` record for `api` -> `YOUR_VPS_PUBLIC_IP` (Proxy: Proxied / Orange Cloud).
2. In **Cloudflare SSL/TLS**:
   - Set Encryption Mode to **Full (Strict)**.
   - Enable **Always Use HTTPS** and **Automatic HTTPS Rewrites**.

## 4. App Directory & Nginx Setup

```bash
# 1. Clone repository
sudo mkdir -p /var/www/nexbyte
sudo chown -R $USER:$USER /var/www/nexbyte
git clone https://github.com/your-org/nexbyte.git /var/www/nexbyte
cd /var/www/nexbyte

# 2. Configure environment file
cp .env.production.lowcost.template .env.production
nano .env.production

# 3. Install dependencies & build Next.js
npm ci --only=production
cd server && npm ci --only=production && cd ..
npm run build

# 4. Start PM2 Processes & Enable Auto-Start on Reboot
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup systemd
# Run the command generated by pm2 startup

# 5. Enable Nginx Dual-Subdomain Config
sudo cp nginx/nexlaptech-lowcost.conf /etc/nginx/sites-available/nexlaptech.conf
sudo ln -sf /etc/nginx/sites-available/nexlaptech.conf /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t

# 6. Issue SSL Certificates via Certbot
sudo certbot --nginx -d nexbyte.com -d www.nexbyte.com -d api.nexbyte.com

# 7. Reload Nginx
sudo systemctl reload nginx
```
