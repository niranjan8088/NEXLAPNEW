# Nex LapTech - Enterprise Production VPS Deployment Guide

This document provides step-by-step instructions for deploying Nex LapTech on a Linux Cloud VPS (DigitalOcean / AWS EC2 / Hetzner / Linode) using **Nginx**, **PM2**, **Cloudflare**, and **Supabase**.

---

## 1. System Requirements & Prerequisites

- **OS**: Ubuntu 22.04 LTS or 24.04 LTS (64-bit)
- **CPU**: 2 vCPU cores minimum (4 vCPU recommended for 10K+ traffic)
- **RAM**: 4 GB RAM minimum
- **Disk**: 40 GB NVMe SSD
- **Node.js**: v20.x LTS or higher
- **Nginx**: 1.18+
- **PM2**: 5.x+
- **Domain**: `nexbyte.com` pointing to VPS public IP via Cloudflare

---

## 2. Server Initialization & Security

```bash
# 1. Update system packages
sudo apt update && sudo apt upgrade -y

# 2. Install Node.js 20 LTS via NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx git certbot python3-certbot-nginx

# 3. Install PM2 globally
sudo npm install -g pm2

# 4. Configure UFW Firewall
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw --force enable
```

---

## 3. Application Directory Setup

```bash
# 1. Create web directory
sudo mkdir -p /var/www/nexbyte
sudo chown -R $USER:$USER /var/www/nexbyte

# 2. Clone Git repository
git clone https://github.com/your-org/nexbyte.git /var/www/nexbyte
cd /var/www/nexbyte

# 3. Copy environment template
cp .env.production.template .env.production
nano .env.production # Fill in your Supabase keys, ports, and domains
```

---

## 4. Building Application & Setting Up PM2

```bash
# 1. Install dependencies
npm ci --only=production
cd server && npm ci --only=production && cd ..

# 2. Build Next.js Production Bundle
npm run build

# 3. Start PM2 Process Ecosystem
pm2 start ecosystem.config.js --env production
pm2 save

# 4. Enable PM2 Auto-Start on Server Reboot
pm2 startup systemd
# Run the command generated by `pm2 startup systemd`
```

---

## 5. Nginx & Let's Encrypt SSL Setup

```bash
# 1. Copy Nginx config
sudo cp nginx/nexbyte.conf /etc/nginx/sites-available/nexbyte.conf
sudo ln -sf /etc/nginx/sites-available/nexbyte.conf /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default

# 2. Test Nginx syntax
sudo nginx -t

# 3. Issue SSL Certificate via Let's Encrypt / Certbot
sudo certbot --nginx -d nexbyte.com -d www.nexbyte.com

# 4. Reload Nginx
sudo systemctl reload nginx
```

---

## 6. Cloudflare Configuration

1. In Cloudflare DNS settings:
   - Add `A` record for `@` pointing to your VPS IP (Proxy status: **Proxied / Orange Cloud**).
   - Add `CNAME` record for `www` pointing to `@` (Proxy status: **Proxied**).
2. In Cloudflare SSL/TLS tab:
   - Set encryption mode to **Full (Strict)**.
   - Enable **Always Use HTTPS** and **Automatic HTTPS Rewrites**.
3. In Cloudflare Security tab:
   - Set Security Level to **Medium**.
   - Enable **Bot Fight Mode**.

---

## 7. Verification & Health Monitoring

```bash
# 1. Test Backend Health Endpoint
curl -i https://nexbyte.com/health

# Output should return:
# HTTP/2 200 
# {"status":"HEALTHY","service":"Nex LapTech Enterprise API Backend",...}

# 2. Check PM2 status
pm2 status
pm2 logs
```
